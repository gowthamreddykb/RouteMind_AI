# Data understanding: DataCo supply-chain dataset


## Scope and source

- File: `DataCoSupplyChainDataset.csv` (cp1252). **180,519 rows x 53 columns.**
- `DescriptionDataCo.csv` and `tokenized_access_logs.csv` were **not supplied**: column meanings below are inferred from names and verified against values, not against official descriptions.


## Structure verified

- Unique `Order Id`: **65,752**; unique `Order Item Id`: 180,519 (= row count). A row is an **order line item**.
- Lines per order: min 1, median 3, max 5; orders with >1 line: 45,902.
- Every shipping/delivery/customer/destination field is identical across lines of one order (checked on 10 fields, 0 conflicts), so **the order is the prediction unit**.
- Fully duplicate rows: 0.
- Customers: 20,652. Date range (orders): 2015-01-01 00:00:00 to 2018-01-31 23:38:00.
